# /docs

Carpeta para los entregables academicos del Trabajo de Grado (no del codigo):

- `log-uso-ia.csv` — registro de uso de IA, para la Declaracion de uso de Inteligencia Artificial de la plantilla institucional. Agrega una fila cada vez que uses una herramienta de IA para avanzar el proyecto.
- Aqui tambien puedes guardar: el SRS (IEEE 830), la plantilla `plantilla-campus-bucaramanga.docx`, actas de reuniones, y cualquier evidencia de las pruebas (matriz de casos de prueba, encuestas de usabilidad).
